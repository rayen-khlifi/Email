# Détection de Spam Email avec Machine Learning

## Description du projet
Ce projet a pour objectif de **déterminer si un message email est un spam ou un message normal (ham)** en utilisant des techniques de **Machine Learning** et de **Traitement du Langage Naturel (NLP)**.

### Exemples :
- Spam : *"Tu as gagné 100£, clique ici !"*
- Normal : *"Bonjour, comment vas-tu ?"

---

## Objectifs
- Analyser le texte des messages
- Classifier les messages en **Spam** ou **Non-Spam**
- Appliquer des techniques de NLP
- Entraîner un modèle de Machine Learning sur **Google Colab**

---

##  Technologies utilisées
- Python 
- Google Colab
- Scikit-learn
- NLP (TF-IDF, Stopwords)

---

## Fonctionnement
1. Chargement des données dans Google Colab
2. Nettoyage du texte (minuscules, suppression des caractères spéciaux)
3. Suppression des mots vides (stopwords)
4. Vectorisation du texte (TF-IDF)
5. Entraînement du modèle
6. Prédiction : **Spam** ou **Normal**
